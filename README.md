# Clash Royale AI Simulator — Android

Это учебный автономный симулятор арены с простым Q-learning. Это отдельная игра-симуляция: она не подключается к официальной Clash Royale и не управляет ею.

## Как получить APK без Android Studio на своём компьютере

В проект добавлен GitHub Actions workflow `.github/workflows/build-apk.yml`. Он собирает APK в облаке GitHub.

1. Создайте аккаунт на https://github.com, если его ещё нет.
2. Создайте новый репозиторий (**New repository**).
3. Распакуйте этот ZIP на компьютере.
4. Загрузите все файлы и папки из этой папки в репозиторий, включая скрытую папку `.github`.
5. Откройте вкладку **Actions** в репозитории.
6. Выберите **Build Android APK** и нажмите **Run workflow**, если сборка не запустилась автоматически.
7. Дождитесь завершения сборки с зелёной галочкой.
8. Откройте запуск и скачайте **ClashRoyaleAI-debug-apk** в разделе **Artifacts**.
9. Распакуйте скачанный ZIP — внутри будет `app-debug.apk`.
10. Передайте APK на Huawei P20 и откройте его. Если Android спросит, разрешите установку приложений из этого источника.

## Совместимость
- Минимальная версия Android в проекте: Android 6.0 (API 23).
- Huawei P20 обычно поставлялся с Android 8.1 и подходит по минимальной версии.

## Возможности прототипа
- 2D-арена, башни и юниты.
- Автоматический бой с простым противником.
- Выбор между ожиданием, ближним бойцом, стрелком и защитой.
- Упрощённое табличное Q-learning обновляет оценки действий.
- Сохранение числа боёв, побед и решений на устройстве.

## Ограничения
- Это прототип с упрощёнными правилами, балансом и обучением.
- Обучение происходит только в собственной симуляции, не в настоящей Clash Royale.
- Проект не связан с Supercell.
